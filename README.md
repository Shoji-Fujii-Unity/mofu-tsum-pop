# MOFU TSUM POP ／ もふもふツムポップ

[日本語](README.md) | [English](README.en.md) | [简体中文](README.zh-CN.md)

もふもふしたツム（マスコット）を **2コ以上つなげて消す**、スマートフォン優先のマッチパズルゲーム。
ビルド不要・サーバー不要で、`index.html` をブラウザで開くだけで動きます。

> ※ ディズニー等の既存キャラクター・商標とは無関係の、オリジナルキャラクターによる自作ゲームです。

---

## 起動方法

```
mofu-tsum-pop/index.html  をダブルクリック（またはブラウザにドラッグ＆ドロップ）
```

- 外部アセット（画像・音声ファイル）は **一切使っていません**。キャラクターも音もすべて実行時に生成します。
- ネットに繋がっていなくても遊べます（Google Fonts だけ CDN。失敗時は自動でシステムフォントにフォールバック）。
- 推奨：スマートフォン（縦画面）／ PC でも遊べます（画面中央にフォン風の枠が表示されます）。

---

## 遊び方

| 操作 | やりかた |
|---|---|
| ツムを消す | 同じ色のツムを **なぞってつなぐ**（2コ以上）。または **タップ** するとつながっているツムをまとめて消します |
| スペシャル | ゲージが満タンで「スペシャル」ボタンが光る → タップで最も多い色を一括消去 |
| ムード | ゲージ満タンで発動。しばらく盤面がほぼ同色になり、大連鎖でスコア ×2 |
| 時間 | 消すと時間が伸びる。制限時間内に「めざせスコア」＋ミッション達成でステージクリア |
| コイン | スコアで稼げる。タイムアップ時にコインで **つづける（+15秒）** が可能（コストは回ごとに増加） |
| キーボード（PC） | `Space` = スペシャル / 開始、`Esc` = 一時停止 |

- ステージは **15問**。★1〜3（ターゲットの 100% / 145% / 200%）。
- ミッション例：「いっぺんに 4ツム 以上つなげよう」「5コンボ 以上」「ムードを 1回 起こそう」。
- ツムが 1つもつながなくなった場合は自動シャッフルします。

## 多言語 / サウンド / セーブ

### 言語
- **日本語 / English / 简体中文** に対応。
- 起動時にブラウザ言語を自動検出。タイトル上部または「せってい → 言語」でいつでも切替（選択は保存されます）。
- 翻訳漏れチェックは自動テストに含まれています（`dev/cdp.js` の `i18n:` 行）。

### サウンド On/Off
- タイトル右上のスピーカーアイコン：SE と BGM の一括 ON/OFF。
- 「せってい」で **効果音(SE)** と **音楽(BGM)** を個別に ON/OFF、スライダーで音量調整。
- 音源は Web Audio API によるリアルタイム合成（ファイル不要）。連鎖長に応じて音程が上行します。
- モバイルでは触った瞬間（ユーザー操作時）にAudioContextを再開するので自動再生規制でも安全。
- 対応端末では振動フィードバック（`navigator.vibrate`）あり。

### セーブデータ（ローカル保存）
- `localStorage` キー： **`mofutsumpop.save.v1`**
- 保存されるもの：言語・SE/BGM・音量／ コイン／ 解放ステージ／ 各ステージのハイスコアと★／ 総合ハイスコア・最大連鎖・最大コンボ・ムード回数・プレイ回数
- ブラウザを閉じても継続。`localStorage` が使えない環境（一部のプライベートモード等）では自動でメモリ内保存に切り替わり、ゲームはそのまま遊べます。
- リセット：「せってい → データをけす」（確認ダイアログあり）。

## 画面レイアウト（縦長）

- アプリ領域は最大幅 470px、高さはいっぱいまで。スマホでは全画面、PCでは中央にフォン枠。
- 盤面は **7列 × 8行** の縦長。`devicePixelRatio` に合わせてキャンバスを再計算するのでRetinaでもくっきり。
- 320×568（小型）〜 1280×860（PC）まで、自動テストで盤面がはみ出さないことを確認済み。
- セーフエリア（ノッチ）対応、ピンチズーム・スクロールは無効。

## ファイル構成

```
mofu-tsum-pop/
├─ index.html        … 画面レイアウト（タイトル／ステージ選択／ゲーム／ダイアログ）
├─ css/style.css     … デザイン（パステル Candy UI、ボタン、HUD、ダイアログ）
├─ js/i18n.js        … 日本語・English・中文 の辞書と言語切替
├─ js/audio.js       … Web Audio 合成（SE 12種 + ループBGM）、ON/OFF・音量
├─ js/store.js       … localStorage セーブ（型ガード・フォールバック・リセット）
├─ js/art.js         … ツム8種の描画（Canvas2D で手続き生成）＋パーティクル
├─ js/levels.js      … 15ステージ定義・★判定・コイン計算・コスト
├─ js/game.js        … 盤面ロジック（入力/連鎖/落下/補充/ムード/スペシャル/採点）
├─ js/app.js         … 画面遷移・HUD・ダイアログ・保存の統合
└─ dev/cdp.js        … Headless Edge + CDP の自動スモークテスト
   dev/shots/*.png   … テストが撮ったスクリーンショット
```

`<script>` はすべて通常スクリプト（ES Module ではない）なので、`file://` 直開きでも動きます。

## 自動テスト

```
cd mofu-tsum-pop
node dev/cdp.js
```

Headless Edge（また Chrome）を CDP で操作し、次を確認します。ログは `dev/cdp-log.txt`、画像は `dev/shots/`。

- JS例外・console.error が 0 件
- 多言語切替（JA/EN/ZH）と翻訳キー欠落チェック
- タイトル → ステージ選択 → 開始 → 実マウス操作で連鎖 → スペシャル → ムード → ポーズ → 結果
- 失敗 → コインでつづける（コイン減算・+15秒・コスト上昇）
- データ削除フロー、リロード後のセーブ継続
- 320×568 と 1280×860 での盤面サイズ・はみ出しチェック
- 長時間の自動プレイ（セル数・パーティクル数のリーク確認）

## 技術メモ

- 描画は単一の `<canvas>`。ツムは 8 種（耳の形・顔・色違い）を 128px のオフスクリーンに事前生成し、拡大縮小＋squash/stretch で描画。
- 落下はセル単位の速度積分（重力 + 着地バウンド）。補充は上部から生成し、一部を隣接色からコピーして連鎖を作りやすくしています。
- 採点：`n(n+1)/2 × 5 × 大きさ補正 × コンボ補正 × ムード×2`（n = 連鎖長）。20コ超は伸びが緩やかになり、1回の消去は最大 9,000点（ムード中の巨大連鎖対策）。
- コンボは 3 秒以内に次の消しをすると継続、表示は HUD と盤上浮上テキスト。
- 手詰まり検出（隣接同色の存在チェック）で自動シャッフル。
- パフォーマンス：56セル + パーティクルで 60fps 目安（描画は事前スプライトの drawImage のみ）。
