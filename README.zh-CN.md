# MOFU TSUM POP / 毛绒扭蛋消消乐

[日本語](README.md) | [English](README.en.md) | [简体中文](README.zh-CN.md)

这是一款优先适配手机的消除益智游戏：连接 **2 个或更多** 毛绒吉祥物即可消除。
无需构建或启动服务器，只需在浏览器中打开 `index.html`。

> 本游戏使用原创角色，与迪士尼或其他现有角色、商标无关。

---

## 开始游戏

```
双击 mofu-tsum-pop/index.html（或将其拖入浏览器）
```

- 不使用任何外部图片或音频资源。角色和声音均在运行时生成。
- 无需联网也可游玩（Google Fonts 使用 CDN；加载失败时会自动回退到系统字体）。
- 推荐在手机竖屏上游玩。也可在电脑上游玩，画面会居中显示为手机样式。

---

## 游玩方法

| 操作 | 方法 |
|---|---|
| 消除吉祥物 | 滑动连接相同颜色的吉祥物（2 个或更多）；也可以点击一个吉祥物，一次消除所有与其相连的同色吉祥物 |
| 特殊技能 | 能量槽满且“特殊技能”按钮发光时，点击按钮即可一次消除数量最多的颜色 |
| 狂热模式 | 能量槽满时触发。短时间内棋盘上的吉祥物几乎变为同一种颜色，超长连锁得分 ×2 |
| 时间 | 消除吉祥物会增加时间。在时间结束前达到目标分数并完成任务即可通关 |
| 金币 | 根据得分获得金币。时间耗尽时可花费金币继续游戏（+15 秒）；每次继续的费用都会增加 |
| 键盘（电脑） | `Space` = 特殊技能 / 开始，`Esc` = 暂停 |

- 共 **15 个关卡**。达到目标分数的 100% / 145% / 200% 可获得 ★1–3。
- 任务示例：“一次连接 4 个或更多吉祥物”“达成 5 连击以上”“触发狂热模式 1 次”。
- 如果棋盘上没有可连接的同色吉祥物，会自动重新排列。

## 语言、声音与存档

### 语言
- 支持 **日本語 / English / 简体中文**。
- 启动时自动检测浏览器语言。可随时通过标题画面顶部的按钮或“设置”切换语言；选择会被保存。
- 自动化测试会检查是否存在缺失的翻译（`dev/cdp.js` 中的 `i18n:` 条目）。

### 声音开关
- 点击标题画面右上角的扬声器图标，可统一开启或关闭音效和背景音乐。
- 在“设置”中可分别开启或关闭**音效（SE）**和**背景音乐（BGM）**，并通过滑块调节音量。
- 使用 Web Audio API 实时合成音频；连锁越长，音调越高。
- 在移动设备上，会在用户操作时恢复 AudioContext，以符合自动播放限制。
- 支持的设备可提供振动反馈（`navigator.vibrate`）。

### 存档（本地保存）
- `localStorage` 键：**`mofutsumpop.save.v1`**
- 保存内容：语言、音效/背景音乐设置和音量 / 金币 / 已解锁关卡 / 各关卡最高分和星级 / 总最高分、最长连锁、最高连击数、狂热模式次数和游玩次数
- 关闭浏览器后进度仍会保留。如果无法使用 `localStorage`（例如部分隐私浏览模式），游戏会自动改用内存保存，仍可正常游玩。
- 重置方法：“设置 → 删除数据”（会显示确认对话框）。

## 画面布局（竖屏）

- 应用区域最大宽度为 470px，并占满可用高度。手机上全屏显示，电脑上则居中显示手机样式画面。
- 棋盘为 **7 列 × 8 行**。画布会根据 `devicePixelRatio` 重新计算，在 Retina 屏幕上也能清晰显示。
- 自动化测试会检查棋盘在 320×568（小屏手机）至 1280×860（电脑）屏幕上不会溢出。
- 支持安全区域（刘海屏）；禁用捏合缩放和页面滚动。

## 文件结构

```
mofu-tsum-pop/
├─ index.html        … 画面布局（标题 / 关卡选择 / 游戏 / 对话框）
├─ css/style.css     … 设计（糖果色 UI、按钮、HUD、对话框）
├─ js/i18n.js        … 日语、英语、中文词典及语言切换
├─ js/audio.js       … Web Audio 合成（12 种音效 + 循环背景音乐）、开关和音量
├─ js/store.js       … localStorage 存档（类型保护、回退、重置）
├─ js/art.js         … 使用 Canvas2D 程序化绘制 8 种吉祥物 + 粒子效果
├─ js/levels.js      … 15 个关卡定义、星级判定、金币计算和费用
├─ js/game.js        … 棋盘逻辑（输入 / 连锁 / 下落 / 补充 / 狂热模式 / 特殊技能 / 计分）
├─ js/app.js         … 整合画面切换、HUD、对话框和存档
└─ dev/cdp.js        … 使用 Headless Edge + CDP 的自动冒烟测试
   dev/shots/*.png   … 测试生成的截图
```

所有 `<script>` 标签均为普通脚本（不是 ES Module），因此可直接通过 `file://` 打开游戏。

```
cd mofu-tsum-pop
node dev/cdp.js
```

测试通过 CDP 控制 Headless Edge（或 Chrome）。日志写入 `dev/cdp-log.txt`，截图写入 `dev/shots/`。

- JavaScript 异常和 `console.error` 均为 0
- 语言切换（JA/EN/ZH）及缺失翻译键检查

- 检查 320×568 和 1280×860 屏幕上的棋盘尺寸及溢出情况
- 长时间自动游玩（检查格子和粒子是否发生泄漏）

## 技术说明

- 使用单个 `<canvas>` 绘制。预先生成 8 种吉祥物（耳朵形状、脸部和颜色各异）的 128px 离屏精灵图，再通过缩放及挤压/拉伸效果绘制。
- 吉祥物采用基于格子的速度积分实现下落（重力 + 落地弹跳）。新吉祥物从顶部生成；部分新吉祥物会复制相邻颜色，让连锁更容易发生。
- 计分：`n(n+1)/2 × 5 × 数量加成 × 连击加成 × 狂热模式×2`（`n` = 连锁数量）。超过 20 个后增长幅度会放缓；单次消除最多计 9,000 分，避免狂热模式中的超长连锁影响过大。
- 3 秒内进行下一次消除即可延续连击。连击会显示在 HUD 中，也会以浮动文字显示在棋盘上方。
- 检测无路可走的情况（检查相邻同色吉祥物），并自动重新排列棋盘。
- 性能目标：56 个格子加粒子时约 60 fps；绘制主要通过预生成精灵图的 `drawImage` 完成。
